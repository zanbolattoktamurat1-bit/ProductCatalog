# ProductCatalog

Қазақ тіліндегі тауар каталогы — ASP.NET Core MVC және .NET 10 көмегімен жасалған оқу жобасы.

## Мүмкіндіктері

- Бастапқыда енгізілген 8 тауарды каталогта көрсету.
- Тауарды атауы бойынша іздеу және категория бойынша сүзу.
- Тауардың толық ақпаратын ашу.
- Валидациясы бар форма арқылы жаңа тауар қосу.
- Responsive интерфейс, Bootstrap 5 және қазақша беттер.

> Тауарлар әзірше жадтағы `List<Product>` ішінде сақталады. Қолданба қайта іске қосылғанда қолданушы қосқан тауарлар сақталмайды.

## Қажетті бағдарламалар

- .NET 10 SDK
- Visual Studio 2022 немесе Visual Studio Code

## VS Code немесе терминалда іске қосу

Репозиторий түбірінен:

```powershell
cd ProductCatalog
dotnet restore
dotnet build
dotnet run
```

Терминалда көрсетілген жергілікті мекенжайды браузерде ашыңыз.

## Visual Studio арқылы

`ProductCatalog/ProductCatalog.sln` файлын ашып, қалпына келтіру аяқталған соң **F5** немесе **Ctrl+F5** басыңыз.
